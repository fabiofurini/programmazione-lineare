# Programmazione lineare

Le dispense del corso di Programmazione lineare online: definizioni, teoremi con le loro dimostrazioni,
esempi svolti, catalogo di problemi ed esercizi con soluzioni, con la stessa numerazione e gli stessi colori
dei PDF. **Il sito è in costruzione**: per ora in italiano c'è solo il capitolo 1; il corso completo è
disponibile in inglese.

**📖 Sito: [fabiofurini.github.io/programmazione-lineare](https://fabiofurini.github.io/programmazione-lineare/)**

## English version

The whole course is available in English:
**[fabiofurini.github.io/linear-programming](https://fabiofurini.github.io/linear-programming/)**
([repository](https://github.com/fabiofurini/linear-programming)).

## Come è costruito

Pagine, figure e PDF sono generati in locale dai sorgenti LaTeX (privati) delle note;
questo repository contiene il sito generato (`docs/`, `mkdocs.yml`). Per vederlo in locale:

```bash
python3 -m pip install mkdocs-material
python3 -m mkdocs serve            # anteprima su http://127.0.0.1:8000
```
